# 경제 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 캔 것을 팔아 골드를 벌고, 그 골드로 증표를 사서 다음 채집이 빨라진다. 죽은 재료 13종이 전부 값을 갖는다.

**Architecture:** 상점과 달인 대금은 **대사가 아니라 등록부**(`shops.csv`·`masters.csv`)가 소유하고, 접근은 순수 술어 `shopAccess` 하나가 판정한다(talk·sell·buy 가 `speakerPresence` 를 공유). 증표 효과는 도구와 합본된 `GatherHand` 로만 판정에 들어간다. 가격은 유도값이고, 빌드가 "산출 매도 ≤ 입력 매도합"으로 돈복사를 영구히 막는다.

**설계 문서:** `docs/superpowers/specs/2026-08-12-economy-design.md` — **§6-앞(평가 반영 규범 20개)이 다른 절보다 우선한다.**
