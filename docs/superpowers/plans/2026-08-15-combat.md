# 전투 구현 계획 (아크 C)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** 사냥터 하나에 들늑대가 시각의 함수로 움직이고, 플레이어가 몸으로 피하며
잡아서 얻은 송곳니로 구리 검을 만든다 — 턴도 틱도 웹소켓도 없이.

**설계:** `docs/superpowers/specs/2026-08-15-combat-design.md` — **§12-앞(규범 26 대조표)이
다른 모든 절보다 우선한다.** 각 태스크는 자기 규범 번호를 §12-앞 에서 찾아 읽는다.

## Global Constraints

- **규범마다 무는 검사를 같은 태스크에서 짠다.** §12-앞 대조표에 "같이 짠다" 표시가
  있는 항 여섯이 그 자리다. 아크 B 에서 자를 들 때마다 데이터가 틀린 쪽이었다.
- **숫자는 재서 말한다.** 측정 조건(손·숙련·척도) 없는 숫자 금지.
- **부등호·판정은 shared 술어 하나에**(transitionGate·nodeAvailable·currentHp 선례).
- **거리는 맨해튼**(§12-앞 6). 시간 수치(예고 700·활성 400·간격 800→400)는 목표값 —
  브라우저에서 재고 바꾸면 결정을 기록한다.
- `apps/client/src/ui/App.tsx` 불가침. `git add -A`/`commit -a` 금지 — 건드린 파일만.
- 에셋 파일 커밋 금지(`public/` 은 글꼴 2개 불변). CREDITS 대장·복원 명령 동반.
- import `.js`; strict; 주석·테스트 이름은 **왜**. 커밋 한국어 + 왜 +
  트레일러 `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- TDD — RED 실제 확인. 태스크 끝 `pnpm data:build && pnpm test && pnpm typecheck` 초록.
  **기준선: 1831 통과 / 86 파일.**

### Task C1: 몬스터는 시각의 함수다

**Files:** Create `packages/shared/src/monster.ts`(+test), Modify `packages/shared/src/types.ts`

- [ ] `MonsterDef`: 순찰 경로(칸 목록) · 공격 목록(예고 시작 오프셋, 예고 길이 ≥700ms,
      활성 길이 ≥400ms, 부채꼴 방향·크기) · **단일 주기 P**(§12-앞 19 — 파서가 다주기를
      거절).
- [ ] `monsterStateAt(def, tMs)`: `t mod P` 로 순찰 칸·**걸음 진행도(0~1)**(§12-앞 16 —
      클라가 직접 보간)·공격 국면(idle/telegraph/sweep)·위험 구역(칸 집합)을 돌려준다.
      정수 ms 산술만(npcStateAt 문법).
- [ ] `combatIntervalMs(proficiency)`: 로그 곡선 재사용, MAX 800 · MIN 400. 주석에
      50ms 교훈(하한이 축을 삼킨 아크 B)을 적는다.
- [ ] RED→GREEN: 주기 경계 연속성, 진행도 단조, 위험 구역이 sweep 국면에만 비지 않음,
      결정론(같은 t → 같은 상태).
- [ ] 커밋.

**Produces:** `monsterStateAt(def: MonsterDef, tMs: number): MonsterState` ·
`combatIntervalMs(p: number): number`
