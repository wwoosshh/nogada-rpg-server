# 노드의 얼굴 구현 계획 (아크 A)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** 맵 위의 색칠한 네모가 나무·바위·꽃·얼음이 된다. **판정은 한 글자도 안 바뀐다.**

**설계 문서:** `docs/superpowers/specs/2026-08-14-node-face-design.md` — **§9-앞(규범 10~15)이 다른 절보다 우선한다.**

## Global Constraints

- **판정 무변경.** 확률표·검증·아이템·레시피·`gather_*.csv` diff 0. **테스트 1,722 가 그대로 초록**이고 새 테스트만 는다.
- **에셋 파일은 하나도 커밋하지 않는다**(§9-앞 10). 잘라 낸 것도 색을 바꾼 것도. `.gitignore` 에 `apps/client/public/nodes/` 를 **A1 에서 먼저** 넣는다 — 지금 그 경로는 무시 목록 밖이라 기본값이 추적이다.
- **모든 가공은 결정적 명령**(§9-앞 11). `CREDITS.md` 하나로 다른 환경에서 재구성돼야 한다.
- **스프라이트는 32×32**(§9-앞 13).
- `apps/client/src/ui/App.tsx` 불가침. `git add -A`/`commit -a` 금지.
- import `.js`; strict; 주석·테스트 이름은 **왜**.
- 커밋 한국어 + 왜, 트레일러 `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
