# 결계 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 네 채집장에 숙련 85,000 결계가 서고, 그 너머의 심층 노드가 자기 표를 굴린다. 못 넘긴 사람은 원래 칸으로 되돌아가며 필요한 숫자를 읽는다. 그리고 출하된 거짓말 셋이 사라진다.

**설계 문서:** `docs/superpowers/specs/2026-08-13-barrier-design.md` — **§9-앞(규범 25개)이 다른 절보다 우선한다.**

## Global Constraints

- 게임 규칙은 `packages/shared` 에만. 서버가 판정의 유일한 주인. **확률표는 클라 번들 금지**(`build.ts` 가 `gather-tables.json` 을 서버 전용으로 굽는 그 경로에 심층 표도 반드시 들어간다 — §9-앞 12). 전환의 `gateSkill/gateValue` 는 **실린다**(요구치를 숫자로 말하는 문).
- **`apps/client/src/ui/App.tsx` 불가침. `git add -A`/`commit -a` 금지.** 커밋 후 `git status --short` 에 그 파일만.
- import `.js`; strict; 주석·테스트 이름은 **왜**; 검증 메시지는 CSV 작가가 읽는다.
- 커밋 한국어 + 왜, 트레일러 `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- 매 태스크 `pnpm data:build && pnpm test && pnpm typecheck`(+클라 태스크는 client build).
- 기존 세이브 무이행. **비운 노드 자리는 벽이 아니라 빈 바닥**(§9-앞 11).

### Task B2: 심층 표 넷 — 분당 산출 ×2.5, ∞ 는 바깥의 복사본

**Files:** Modify `packages/data/csv/gather_tables.csv`·`gather_tiers.csv`·`gather_brackets.csv`·`nodes.csv`, `packages/data/src/validate.ts`(+test), `packages/data/src/gatherSimulation.test.ts`

**Interfaces:** 새 표 id 는 `ice_deep`·`wood_deep`·`mineral_deep`·`herb_deep`. 티어 사다리는 바깥과 **같은 25종**(만점 100 이 안 바뀐다).

- [ ] **목표치는 최상위 티어 배수가 아니라 분당 산출**(§9-앞 6). 계열마다 브라켓을 따로 지어 **매도가 기준 분당 산출 ×2.5(±15%)** 를 맞춘다. 나무는 최상위(`golden_fruit` 6,500G)가 tier2(`tree_fruit` 3,200G)의 2.03배뿐이고 tier2 가 이미 19% 라 **최상위만 올려서는 못 맞춘다** — tier2 이하를 움직인다.
- [ ] **불변식 두 개를 빌드 검증으로**(§9-앞 1·7):
  - `심층 표의 ∞ 브라켓은 바깥 ∞ 와 티어별로 동일하다.`
  - `심층의 어느 유한 브라켓도 최상위 티어가 바깥 ∞ 의 10% 를 넘지 않는다.`
- [ ] **유한 브라켓을 500,000 까지 깐다**(§9-앞 3) — 간격은 `유한 상한 최댓값 + 1` 로 재므로 85,000 에서 끝나면 67ms(바닥 50ms 가 아님)라 ∞ 를 복사해도 40.2분(위반)이 나온다.
- [ ] **계열 간 형평 검증**(§9-앞 6): 네 계열의 "심층 ÷ 바깥 분당 산출" 편차가 ±15% 안. 메시지는 CSV 작가가 읽는다 — 어느 계열이 몇 배이고 목표가 얼마인지 적는다.
- [ ] **전수 시뮬의 표 목록 하드코딩을 푼다**(§9-앞 5): `gatherSimulation.test.ts:170,236` 의 `['ice','wood','mineral','herb']` → `Object.keys(tables)`.
- [ ] `nodes.csv` 의 deep variant 넷이 `*_deep` 을 가리키게 한다. **`variant='deep' ⟺ tableId 가 *_deep` 을 검증 한 줄로 묶는다**(둘이 갈라지는 날을 막는다).
