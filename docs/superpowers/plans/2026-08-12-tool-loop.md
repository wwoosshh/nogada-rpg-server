# 도구 루프 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 시작 마을 도구 1개로 시작해 맨손으로 재료를 모아 첫 도구를 만드는 순간 채집이 빨라지고, 중복 제작품은 강화 재료가 되며, 도구는 손으로 바꿔 낄 수 있다.

**Architecture:** 도구 효과는 shared 의 `gatherToolProfile`/`gatherIntervalMs` 단일 이음새로 — 서버 스탬프와 클라 표시가 같은 함수를 부른다. 게이트 대신 맨손 페널티(간격 ×1.5, roll ×1.45). 신규 API `POST /api/equip`·`POST /api/enhance`. 도달 가능성 검증은 "배치된 노드의 표 = 무조건 도달"로 3차 재작성.

**설계 문서:** `docs/superpowers/specs/2026-08-12-tool-loop-design.md` — **§6-앞(평가 반영 규범 17개)이 다른 절보다 우선한다.**

### Task T1: shared 이음새 — 도구 프로필·간격·강화가 한 곳에 산다

**Files:** Create `packages/shared/src/formulas/toolProfile.ts`(+test), Modify `packages/shared/src/formulas/gatherTable.ts`(+test), `packages/shared/src/formulas/craft.ts`(+test), `packages/shared/src/equipment.ts`(+test), `packages/shared/src/index.ts`, `packages/data/src/content-cli.ts`, `packages/data/src/gatherSimulation.test.ts`

**Interfaces:** Produces —
```ts
export interface GatherToolProfile { rollFactor: number; intervalFactor: number; jackpotFlat: number }
export function gatherToolProfile(def: ItemDef | null): GatherToolProfile
// null(맨손)·엉뚱한 기술 도구 = { 1.45, 1.5, 0 } / 1티어 { 1.0, 1.0, 0 } / 2티어 { 0.9, 0.8, 2 } / 3티어 { 0.8, 0.6, 3 }
export const ENHANCE_CAP = 5
export const ENHANCE_INTERVAL_FACTOR = 0.97      // 채집 도구 +1당
export const HAMMER_ENHANCE_CHANCE_BONUS = 0.005 // 망치 +1당 성공률
export interface EquippedToolInfo { def: ItemDef; instance: ItemInstance }
export function equippedToolInfo(player: PlayerState, skill: SkillId, items: Record<string, ItemDef>): EquippedToolInfo | null
export function gatherIntervalMs(proficiency: number, tool: EquippedToolInfo | null): number
// max(ACTION_INTERVAL_MIN_MS, actionIntervalMs(prof) × intervalFactor × ENHANCE_INTERVAL_FACTOR^enhanceLevel) — 하한은 배수 뒤 클램프(§6-앞 6)
```
`gatherOutcome(table, prof, tool: ItemDef | null, rng)` — null 허용, 내부는 `gatherToolProfile` 만 사용(조용한 기본값 금지). `CraftContext` 에 `enhanceLevel: number` 추가, `calcCraftSuccess` 에 `+ enhanceLevel × HAMMER_ENHANCE_CHANCE_BONUS`(§6-앞 10).

- [ ] RED→GREEN: toolProfile 테스트 — 맨손/엉뚱한 기술 도구/3티어, **불변식: 상위 티어 기본 intervalFactor < 하위 티어 × 0.97^ENHANCE_CAP**(§6-앞 1 — 철 0.8 < 0.8587, 미스릴 0.6 < 0.687).
- [ ] RED→GREEN: gatherIntervalMs — 강화 곱, 하한 클램프 순서, 맨손 ×1.5.
- [ ] gatherOutcome null 경로 + 시뮬 확장: 맨손 vs 구리 분포(성공 20%→13.8% 급 차이, §6-앞 3)·간격. `canGather` 은퇴(주석 포함).
