# 일과 쓰는 법

이 폴더의 `.sched` 파일 하나가 **화자 한 명의 하루**다. 파일 이름(확장자를 뗀 것)이
곧 화자 id 이고, `csv/speakers.csv` 의 `id` 칸과 같아야 한다. 한 줄은 `HH:MM 지점` 이며
그 시각에 그 지점에 **도착해 있다**는 뜻이다 — 출발 시각은 빌드가 길 길이로 역산하니
적지 않는다. 지점은 맵 파일(`maps/*.tmx`)의 `places` 오브젝트 레이어에 이름으로 찍어
두고(속성 `indoor` 를 켜면 그 시각엔 실내로 사라진다), `A | B` 로 적으면 날마다 둘 중
하나를 골라 간다. 마지막 줄의 지점에서 다음 날 첫 줄까지 머물며, 한 줄만 적으면 하루
종일 그 자리다. `#` 로 시작하는 줄과 빈 줄은 메모다. 고친 뒤 `pnpm data:build` 를
돌리면 없는 지점·불가능한 시각·못 걸어가는 구간을 어느 파일 몇 행인지와 함께 한국어로
알려 준다 — **오류는 실패가 아니라 안내다.**

```
# 여관안주인 — 여관을 지키다 낮에 광장에 다녀온다
06:00 여관앞
09:00 눈광장
13:00 여관안
15:00 눈광장 | 여관앞
22:00 여관안
```
